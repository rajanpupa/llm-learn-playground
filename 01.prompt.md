### LLM training visualization 

Create a complete website to learn step by step how a llm is trained. Divide the lessions into smaller modular byte size pages which is easy to understand. There should also be visualizations that clears the concept easily. 

- User can open the website and start learning.
- Each learning page is titled 01. <title>, 02. <title 2> and so on.
- The flow should be natural from page 1 to page 2.
- Each page should have very clear examples, and visualizations to make the concepts easy to understand.
- The same example should continue page after page - so that the students don't get confused.

you can use this repo as reference for the steps: https://github.com/angelos-p/llm-from-scratch
